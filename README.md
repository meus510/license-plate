# MEUS Custom Bracket Preview Studio

고객이 번호판 브라켓 문구나 로고의 시안을 만들고 PNG와 제작 설정값을 저장하는 정적 웹사이트입니다.

## 실행

압축을 풀고 `dist/index.html`을 Chrome에서 엽니다. 별도 설치나 빌드가 없습니다. 외부 폰트·Tailwind CDN 때문에 인터넷 연결이 필요합니다. 로컬 파일에서 클립보드 자동 복사가 제한되면 표시된 설정값을 직접 복사할 수 있습니다.

마킹 부분 확대는 화면 폭859px 이하에서만 보입니다. PC에서는 창 폭을 줄여 모바일 UI를 확인할 수 있습니다.

## GitHub로 옮기기

1. `START_HERE.txt`와 `HANDOFF.md`를 읽습니다.
2. 사용자 소유의 대상 저장소와 공개 범위를 정하고 GitHub 인증을 완료합니다. 인증 토큰을 HTML이나 문서에 넣지 않습니다.
3. ZIP을 푼 폴더의 내용을 저장소에 커밋/푸시합니다. 이 ZIP에는 `.git` 이력이 들어 있지 않습니다. 새 저장소로 옮길 때 필요하면 이 폴더에서 Git을 초기화합니다.
4. 기존 저장소가 있다면 그 저장소를 먼저 가져와 변경사항을 반영합니다. 기존 파일을 무조건 덮거나 강제 푸시하지 않습니다.
5. 웹사이트를 공개할 때 배포할 정적 폴더는 `dist`이며 진입 파일은 `index.html`입니다. 빌드 명령이 필요하지 않습니다.

GitHub 푸시만으로 고객용 사이트 공개가 완료되는 것은 아닙니다. 배포 서비스와 공개 범위는 별도로 결정합니다. 이전에 지정한 GitHub 대상은 https://github.com/meus510/license-plate (Private, main)입니다. 현재 연결 권한과 저장소 상태를 먼저 확인하세요. 고객용 배포처는 확정하지 않았으며 자동 배포 workflow는 포함하지 않았습니다.

`.openai/hosting.json`은 기존 Sites 연결용입니다. 다른 호스팅은 이 파일을 사용하지 않습니다. 기존 Sites 반영이 필요하면 해당 프로젝트와 게시 권한을 유지하세요.

## 파일 구조

- `dist/index.html`: 유일한 실행·수정 기준 파일. CSS/JavaScript/이미지가 내장되어 있습니다.
- `assets/`: 전달받은 원본 이미지 참고용. 이 파일을 바꿔도 내장 이미지가 자동 교체되지는 않습니다.
- `HANDOFF.md`: 구현된 기능, 치수, 제약, 남은 작업.
- `START_HERE.txt`: 다음 채팅에 붙여 넣을 인계 요청.
- `SNAPSHOT.json`: 생성 시점의 소스·게시 정보와 파일 해시.

최초 Gemini 파일과 예전 게시본은 혼동을 피하기 위해 포함하지 않았습니다.
